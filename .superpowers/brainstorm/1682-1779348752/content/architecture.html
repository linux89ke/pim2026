What happens when a reviewer clicks Approve
1
Reviewer clicks Approve on a product card in the shell
2
Shell sends fetch('POST /approve', {id: ...}) directly to api.py — ~20ms
3
api.py writes the decision to the parquet cache — no Streamlit rerun
4
Shell receives 200 OK, animates the card to "Approved" state — instant
5
Stats counter updates client-side — no page reload needed
90% of your existing code stays. The QC rules, parquet cache, flag cache, export logic, and Streamlit upload flow are untouched. Only the visual layer (what the reviewer sees) gets rebuilt.
